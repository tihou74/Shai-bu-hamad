# content/ — النصوص والبيانات

## البروفايل → `content/profile/`

**هذا الصندوق ما يقدر يقرأ ملفّات PDF** — لا `pdftotext` ولا أي بديل، والشبكة مغلقة فما أقدر أركّب أدوات.

فاختر واحدة من هذي الطرق:

| الصيغة | تنفع؟ | ملاحظة |
|---|---|---|
| **النصّ منسوخاً في المحادثة** | ✅ **الأفضل** | الأسرع والأدقّ — بلا أي خطر |
| `.docx` / `.pptx` | ✅ | أقدر أفتحهما وأستخرج النصّ |
| `.txt` / `.md` | ✅ | مثالي |
| **صور صفحات البروفايل** | ✅ | ارفعها هنا، كل صفحة صورة، وأفحص أبعادها قبل فتحها |
| `.pdf` | ⚠️ | ارفعه كمرجع، بس أرسل لي معه النصّ أو الصور |

المطلوب في البروفايل:
- قصّة التأسيس (2025) ومن هو «بوحمد»
- الرؤية والرسالة
- ما يميّزنا — ليش شاي بوحمد مو مثل غيره
- نبرة البراند

## المنيو → `content/menu/`

أفضل شي: **جدول** (Excel / CSV / أو مكتوب في المحادثة) بهذي الأعمدة:

```
التصنيف | الاسم عربي | الاسم إنجليزي | الوصف | السعر (ر.ق) | الحجم | صورة | مميّز؟
```

> المنيو راح يُبنى من **ملفّ JSON واحد** — يعني تحديث سعر أو إضافة صنف لاحقاً
> يصير بتعديل سطر واحد، بلا لمس أي كود. هذا مقصود.
