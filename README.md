## أين أرفع ملفّاتي؟

| أرفع هنا | ما يوضع فيه |
|---|---|
| [`brand/`](brand/) | الشعار، الألوان، الخطوط، دليل الهويّة |
| [`content/`](content/) | البروفايل، المنيو، بيانات الفروع |

> وكل مجلّد فيه `README.md` يشرح الصيغ المقبولة — اقرأه قبل الرفع.

## قواعد تسمية الملفّات

- **أحرف لاتينيّة فقط**: `karak.jpg` ✅ · `كرك.jpg` ❌ — المسارات العربيّة تنكسر على الاستضافة
- بلا مسافات: استخدم `-` مثل `west-walk-interior.jpg`
- بأحرف صغيرة
