# brand/ — هويّة البراند

## الشعار → `brand/logo/`

**الصيغة المفضّلة: فيكتور** (`.svg` · `.pdf` · `.ai` · `.eps`)
الفيكتور يتكبّر بلا حدود، ويتحوّل لأي مقاس وأي لون، وما له أبعاد بكسل — فلا خطر على حدّ 2000 بكسل.

إذا ما توفّر فيكتور: `PNG` بخلفيّة شفّافة، بأعلى دقّة متوفّرة (ارفعه هنا بأي مقاس — أفحصه بالحارس قبل فتحه).

النسخ المطلوبة:

| الملفّ | الوصف |
|---|---|
| `logo-primary.svg` | الشعار الأساسي |
| `logo-horizontal.svg` | التخطيط الأفقي |
| `logo-stacked.svg` | التخطيط العمودي |
| `logo-mark.svg` | الرمز/الأيقونة وحدها (بلا نصّ) |
| `logo-white.svg` | أحادي أبيض — للخلفيات الداكنة |
| `logo-black.svg` | أحادي أسود |

## الألوان → `brand/colors/`

ملفّ نصّي أو صورة من دليل الهويّة، فيه القيم **الحقيقيّة**:

```
العنّابي الأساسي   HEX #______   Pantone ____   CMYK __/__/__/__
```

> ⚠️ لا تتركني أستخرج الألوان من صورة — الصور مضغوطة والقيم تطلع خاطئة بدرجة أو درجتين،
> والفرق يبيّن بين الموقع والمطبوعات واللافتة.

## الخطوط → `brand/fonts/`

ملفّات الخطّ العربي **واللاتيني**: `.woff2` (الأفضل للويب) · `.otf` · `.ttf`
ومعها **اسم الترخيص** في `brand/fonts/LICENSE.txt`.

> الخطوط تُستضاف على موقعنا مباشرة — لا Google Fonts ولا أي خدمة خارجيّة.
> هذا قرار أمني (صفر طرف ثالث) وقرار أداء في الوقت نفسه.
