### شروط `.qa` — وأنت تستوفيها

النطاق تديره **سجلّ نطاقات قطر (QDR)** التابع لهيئة تنظيم الاتّصالات (CRA).
والمصادر تتناقض: بعض المُسجّلين يقول إنه مفتوح للجميع، وآخرون يقولون إنه
محصور بمن يملك **رخصة تجاريّة قطريّة** أو **علامة تجاريّة مسجّلة في قطر**.

**وهذا التناقض لا يعنيك**، لأن عندك شركة مسجّلة — «شركة مطاعم شاي بو حمد
لتقديم الوجبات و المشروبات» — فسجلّك التجاري يستوفي أصعب التفسيرات.

**جهّز:** السجلّ التجاري (CR) · هويّة المفوّض بالتوقيع · بريد ورقم تواصل.

> المصادر: [سياسة نطاق ‎.qa](https://www.aeserver.com/support/qa-domain-name-policy-explained/) ·
> [شروط Gandi](https://www.gandi.net/en-US/domain/tld/qa) ·
> [مُسجّل قطري](https://qhost.qa/) · السجلّ الرسمي: <https://domains.qa>.
> تمّت إعادة صياغة المحتوى امتثالاً لقيود الترخيص. والأسعار تتغيّر — تحقّق عند الشراء.

**ونقطة مهمّة:** تسجيل النطاق **ليس** تسجيل علامة تجاريّة. النطاق يمنعك من
التشابه في العنوان فقط. وتسجيل العلامة في قطر هو ما يمنحك حقّاً قابلاً
للتنفيذ على الاسم والشعار — وهو مطلوب منك أصلاً في `docs/rights.md`، وقد
يُسهّل عليك شروط `.qa` في الوقت نفسه.

## 2 · أين يُستضاف؟ — القرار الأهمّ في هذا الملفّ

النطاق وحده لا يكفي. ومع النطاق يُحسم سؤال الاستضافة:

| | GitHub Pages (الحالي) | **Cloudflare Pages (المُوصى به)** |
|---|---|---|
| السعر | مجاني | مجاني |
| النطاق الخاصّ | ✅ | ✅ |
| شهادة HTTPS | ✅ تلقائيّة | ✅ تلقائيّة |
| **رؤوس الأمان `_headers`** | ❌ **يتجاهلها** | ✅ **يقرأها** |
| `Strict-Transport-Security` | ❌ مستحيل | ✅ |
| `frame-ancestors` (منع التأطير) | ❌ مستحيل | ✅ |
| شبكة التوصيل | جيّدة | أسرع في الخليج |

**في مستودعك ملفّ `_headers` مكتوب ومكتمل — و GitHub Pages لا يقرأه.** أي أن
نصف عمل الأمان معطّل اليوم، والبديل الموجود هو وسم `<meta>` للـCSP وحده،
وهو لا يستطيع تنفيذ HSTS ولا منع التأطير. التفصيل في `docs/security.md`.

**فالتوصية: مع النطاق، انقل الاستضافة إلى Cloudflare Pages.** الربط من نفس
مستودع GitHub، بلا أمر بناء (الموقع ثابت)، وكل دفعة إلى `main` تُنشر تلقائياً
كما الآن.

## 3 · سجلّات DNS

### إن بقيت على GitHub Pages

للنطاق الجذري `shaibuhamad.qa` — أربعة سجلّات `A`:

```
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
```

واختيارياً أربعة `AAAA` لـIPv6:

```
2606:50c0:8000::153
2606:50c0:8001::153
2606:50c0:8002::153
2606:50c0:8003::153
```

ولـ `www` — سجلّ `CNAME` واحد إلى `tihou74.github.io`.

> هذه العناوين مقروءة من **توثيق GitHub الرسمي** لا من الذاكرة
> ([المصدر](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site)).
> وGitHub يوصي بإضافة `A` مع `AAAA` لا `AAAA` وحده. تحقّق منها عند التنفيذ:
> عنوان قديم = موقع معطّل.

### إن انتقلت إلى Cloudflare Pages

لا تحتاج عناوين IP. تنقل **خوادم الأسماء** (nameservers) للنطاق إلى
Cloudflare، ثم تربط النطاق من لوحة Pages فتُنشأ السجلّات تلقائياً.

## 4 · ما يتغيّر في المستودع — نفّذه أنا، لا أنت

هذه كلها معطّلة أو ناقصة اليوم **لأنها تحتاج عنواناً نهائياً**:

| | الحال اليوم | بعد النطاق |
|---|---|---|
| `CNAME` | غير موجود | يُنشأ باسم النطاق |
| `og:image` | **مسار نسبي ← معاينة واتساب مكسورة** | رابط مطلق |
| `og:url` | غير موجود | يُضاف |
| `canonical` | غير موجود | يُضاف |
| `twitter:card` | غير موجود | يُضاف |
| `sitemap.xml` | غير موجود | يُنشأ |
| `robots.txt` | غير موجود | يُنشأ |
| البيانات المنظّمة | مسارات نسبيّة | مطلقة |
| `_headers` | يتجاهلها المضيف | تعمل على Cloudflare |

> **أهمّها عملياً `og:image`.** هو مسار نسبي الآن، ومنصّات المشاركة تتطلّب
> رابطاً مطلقاً — فحين ترسل موقعك في واتساب **لا تظهر أي صورة**. وهذا أوّل
> ما يفعله أي زبون برابطك.

- **لا تشترِ استضافة** مع النطاق. موقعك ثابت ويُستضاف **مجاناً**، ومن يبيعك
  «استضافة ولوحة تحكّم» يبيعك ما لا تحتاجه. اشترِ **النطاق وحده**.
- **لا تسجّل النطاق باسم شخص آخر** — لا مصمّم ولا وكالة. النطاق أصل من أصول
  الشركة، وتسجيله باسم غيرك يعني أن استعادته تحتاج موافقته. **السجلّ التجاري
  للشركة هو المالك.**
- **لا تنسَ التجديد.** نطاق منتهٍ = موقع ميّت وبريد معطّل. فعّل التجديد
  التلقائي، وضع تذكيراً سنوياً.
- **لا تربط البريد الإلكتروني بالموقع.** البريد (`info@shaibuhamad.qa`) خدمة
  منفصلة عن الاستضافة — رتّبها حين تريدها، ولا تشترِ استضافة من أجلها.
